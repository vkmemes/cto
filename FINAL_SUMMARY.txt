 NEXT STEPS (FOR USER)

1. Install Dependencies
   cd /path/to/project
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

2. Configure Environment
   cp .env.example .env
   nano .env  # Set BOT_TOKEN, CHANNEL_USERNAME, etc.

3. Initialize Database
   python migrate.py

   nano schedule.json  # Add your groups and schedule
