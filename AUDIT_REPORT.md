# Аудит и оптимизация ЯГК Schedule

## Краткий итог
Проект в целом построен корректно: разделение на Core/DB/Bot/Web сохранено, асинхронные операции используются последовательно, код читаем и пригоден для поддержки. Ниже — перечень доработок, которые выполнены для повышения стабильности, экономии ресурсов, а также значительных улучшений UX.

## Что оптимизировано в коде

### Core (core.py)
- Добавлена карта быстрого поиска групп (нормализованные названия → ключ группы), чтобы избежать линейного поиска по списку при каждом запросе.
- Кэш замен теперь индексируется по нормализованному названию группы — это устраняет повторную нормализацию и перебор.
- Введён единый HTTP-клиент и блокировка для запросов замен, чтобы не плодить соединения и исключить гонки кэша.
- **Упрощена логика групп**: убрано разделение групп по символу `/`. Группы типа "СА1-11/СА1-12" теперь рассматриваются как единые сущности.
- **Добавлен метод `search_groups()`**: умный поиск групп по подстроке с 4-уровневой приоритизацией:
  1. Точное совпадение после нормализации
  2. Название начинается с поискового запроса
  3. Название содержит поисковый запрос
  4. Поиск в оригинальном названии (case-insensitive)

### Database (database.py)
- Для SQLite используется `NullPool`, что снижает накладные расходы и корректнее для одиночного файла БД.
- Массовые операции (сброс флага болезни, удаление домашних заданий) переведены на SQL `UPDATE/DELETE`, чтобы не загружать сущности в память.

## Рекомендации для сервера с 8GB RAM

### Производительность
- **Uvicorn**: запускать 1–2 воркера (`--workers 1` или `2`) — избыточное количество не даст преимущества из-за SQLite и может увеличить память.
- **SQLite**: использовать один процесс, где возможно, либо вынести БД в отдельный сервис (PostgreSQL) при росте нагрузки.
- **Telegram Bot**: при высоких рассылках держать паузу (`sleep`) 50–100 мс между отправками, как сделано сейчас.

### Надёжность
- Включить ротацию логов (logrotate), иначе файлы логов будут расти бесконечно.
- Убедиться, что `REPLACEMENT_URL` отвечает быстро; при нестабильной сети увеличить таймаут до 15–20 секунд.

### Пользовательский опыт

```

2. Бот: 👋 Добро пожаловать! Введите название группы...

   2. СА1-12
   ...

   Новая группа: ИС1-21
   Предыдущая группа: СА1-11
   Ваши данные сохранены.
```
