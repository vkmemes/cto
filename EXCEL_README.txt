БЫСТРЫЙ СТАРТ:
-------------------------------------------------------------------------------

1. Автоматическая конвертация всех Excel файлов (РЕКОМЕНДУЕТСЯ):

   python excel_to_schedule.py

   Конвертер автоматически найдёт все .xlsx файлы в папке и объединит их
   в один schedule.json.

   Текущие файлы:
   - mmo_2sem.xlsx    (МА, ТТ группы)
   - oar_2sem_.xlsx   (ОАР группы)
   - oep_2sem.xlsx    (ОЭП группы)
   - oit_2sem.xlsx    (ИС, СА, ИБ группы)
   - so_2sem.xlsx     (СТ, СД, МО группы)

   Результат: schedule.json с 208 группами

2. Конвертация отдельного файла:

   python excel_to_schedule.py oit_2sem.xlsx my_schedule.json

   Полезно для тестирования или конвертации одного файла.

3. Проверка результата:

   python -c "import json; d=json.load(open('schedule.json')); print(f'Групп: {len(d[\"groups\"])}')"

4. Запуск системы:

   # Бот
   python bot_main.py

   # Веб-сервер
   python web_main.py

ФОРМАТ EXCEL ФАЙЛОВ:
-------------------------------------------------------------------------------

Общий формат для всех файлов:
- Листы: несколько листов (по курсам/специальностям)
- Группы: множественные группы на лист
- Структура на листе:
  * Строка 1: Название группы ("ИС1-11/ИС1-12")
  * Дни недели: "Понедельник", "Вторник", ...
  * Пары:
    - Колонка 1: Номер пары (1-6)
    - Колонка 2: Предмет
    - Колонка 6: Преподаватель
    - Колонка 9: Кабинет

- Нет разделения на числитель/знаменатель
- Расписание одинаковое для обеих недель
