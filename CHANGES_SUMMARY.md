# Изменения в проекте ЯГК Schedule

## Исправление проблемы с отображением пар с номером 0

### Проблема
Бот и веб-интерфейс неправильно отображали номера пар:
- Использовался индекс массива вместо реального номера пары (`index + 1`)
- Парсер Excel игнорировал пары с номером 0 (только 1-8)
- При пропусках в расписании номера отображались некорректно

### Решение
1. **core.py**
   - Добавлено поле `pair_number` в модель `Lesson` (дефолтное значение 0)
   - Обновлен `get_schedule_for_date()` для чтения номера пары из JSON
   - Обновлен `parse_replacements_html()` для сохранения номера пары
   - Обновлен `format_schedule_text()` для использования реального номера пары

2. **excel_to_schedule.py**
   - Изменена функция `is_pair_number()` для обработки номеров 0-8 (было 1-8)
   - Добавлено время для пары №0: "07:00-08:30"
   - Обновлена функция `parse_lesson()` для сохранения `pair_number` в JSON

3. **schedule_view_template.html**
   - Изменено отображение с `index + 1` на `lesson.pair_number`
