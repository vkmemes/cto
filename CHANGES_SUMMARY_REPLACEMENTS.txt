Сводка изменений: Исправление проблемы с заменами в расписании

================================================================================
ПРОБЛЕМА
Бот не применял замены к расписанию - при наличии замен возвращались только
замены, а базовое расписание полностью игнорировалось.

================================================================================
РЕШЕНИЯ
1. Исправлена логика применения замен в методе get_schedule_for_date()
   - Теперь замены применяются к базовому расписанию, а не заменяют его
   - Заменяются только конкретные пары, для которых есть замены
   - Остальные пары остаются из базового расписания

2. Добавлено определение номера пары по времени
   - Создана функция get_pair_number_from_time()
   - Добавлена константа PAIR_TIMES с временами всех 7 пар
   - Пары в базовом расписании и заменах теперь определяются по времени

3. Обновлён парсер HTML для замен
   - Теперь использует get_pair_number_from_time() для определения номера пары
   - Сохраняет fallback на последовательную нумерацию при ошибке парсинга

4. Улучшена обработка ошибок при загрузке замен
   - Добавлена отдельная обработка HTTP-ошибок
   - Улучшено логирование с префиксом [ScheduleManager]

================================================================================
ИЗМЕНЁННЫЕ ФАЙЛЫ
1. core.py - основные исправления логики замен
2. .gitignore - добавлен шаблон test_*.html
3. FIX_REPLACEMENTS.md - подробная документация

================================================================================

ДАЛЬНЕЙШИЕ ДЕЙСТВИЯ
Для работы замен в продакшене:
1. Настроить переменную окружения REPLACEMENT_URL с правильным URL
2. Убедиться, что HTML-структура страницы замен соответствует ожидаемой
3. Проверить наличие всех необходимых полей в HTML (время, предмет, преподаватель, аудитория)
